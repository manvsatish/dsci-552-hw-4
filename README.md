# DSCI 552 Homework 4

Homework 4 DSCI 552 - Machine Learning for DS

## Structure

- `notebook/Satish_Manvika_HW4.ipynb`: completed Jupyter Notebook
- `data/AReM.zip`: AReM activity-recognition dataset
- `requirements.txt`: required Python packages

## Running the notebook

Install the required packages from the repository root:

```bash
pip install -r requirements.txt
```

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open `notebook/Satish_Manvika_HW4.ipynb` and run all cells in order!
